# Nodex

**Nodex** is a modern full-stack conferencing application designed for real-time video meetings, voice calls, and team collaboration.  
It allows users to create and join meetings, communicate securely, and collaborate seamlessly from anywhere.

Nodex focuses on a clean user experience, high performance, and reliable real-time communication, inspired by modern collaboration platforms like **Zoom**.
